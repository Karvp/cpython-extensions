HARDENING DELIVERED
===================
- Added explicit inline binding modes:
  * binding="frozen" (default): backward-compatible decoration-time snapshot semantics.
  * binding="guarded": evaluate-once callable guard with ordinary-call deoptimization.
- Guarded inline fast path validates target identity and the cloned function state that
  is relevant to the call shape, including code/default state. Complex callable shapes
  use conservative identity/state snapshots without invoking user equality.
- Dynamic global/closure rebinding, function __code__ replacement, relevant defaults,
  method replacement, functools.partial mutation, and callable-object type.__call__
  replacement are covered by focused regressions.
- Guard failure reuses the callable already loaded for that invocation; descriptor/global
  lookup is not repeated merely because the inline path deoptimizes.
- policy="speed" accounts for guarded validation cost and can retain an ordinary CALL
  when guarded expansion is statically unprofitable.
- Shared inline regions support guarded binding and deopt correctly after target changes.
- binding="frozen" remains the default so 1.0.1 applications do not silently gain runtime
  guards or lose existing optimizer freedom.
- Added a comprehensive production guide under docs/COMPREHENSIVE_GUIDE.md.

SEMANTIC BOUNDARIES
===================
- Guarded binding is intended to preserve changes occurring between calls. It is not an
  atomic synchronization protocol for arbitrary concurrent mutation while another thread
  executes the target; applications need the same synchronization they would use around
  ordinary dynamic mutation.
- freeze_globals=True and freeze_closures=True intentionally snapshot dependencies.
  Guarded callable validation cannot make deliberately frozen dependencies dynamic again.
- fusion_strategy="aggressive" remains an explicit observability tradeoff for users who
  accept reduced trace/f_locals visibility of synthetic/local materialization.
- Live switch modes remain explicit low-level modes with mode-specific re-entry/concurrency
  contracts. Portable/auto is the production default.
- enable_goto(mode="strict") remains the production default; unsafe mode is not claimed as
  a general safe control-flow facility.
- Certification is for ordinary CPython 3.13.5. A free-threaded CPython 3.13t executable
  was not available in this environment and is not claimed as independently certified.
