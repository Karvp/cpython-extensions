python_extensions 0.21.0 certification
======================================
Runtime: CPython 3.13.5
Scope: pyswitch + inline_function/inline_calls + pygoto

Release changes
---------------
* Inline: exact registered functions loaded through a caller free-variable cell may be inlined behind an operand-stack identity guard. The original LOAD_DEREF value is retained and reused by the cold fallback CALL, so nonlocal rebinding preserves one-time callable lookup. policy="speed" charges five guard instructions and rejects the trivial guarded call; policy="always" exposes the guarded transform. Telemetry: guarded_closure_calls.
* Switch: compact_routes="auto" is an opt-in density heuristic. It hoists only source-location-identical route suffixes and requires a duplicated-AST gain >= 24. compact_routes=False remains the speed-first default.
* Goto: patched code is explicitly passed through verify_code before report attachment. Telemetry: synthetic_jumps_verified (goto jumps + label-skip jumps), with zero-valued no-op reporting for marker-free functions.
