# Code of Conduct

This project expects technical collaboration to remain respectful, constructive, and focused on the work.

Be specific when reviewing code, distinguish evidence from speculation, and critique implementations rather than people. Harassment, threats, discriminatory abuse, deliberate disruption, doxxing, or publication of another person's private information is not acceptable.

Maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the project and its contributors.

If a conflict concerns a security vulnerability, use the private reporting path described in `SECURITY.md` rather than escalating it publicly.
