0.22 refinements
----------------
Inline:
- Guarded closure speed profitability is body-aware: concrete fold/prune reductions may repay the identity guard.
- Public telemetry: guarded_closure_speed_accepted and guarded_closure_body_credit.
- Closure-held registered bound methods and positional-only functools.partial objects are supported behind the same evaluate-once identity guard.
- Keyword-bearing partials and generic callable instances remain ordinary calls because behavior can mutate without object identity changing.

pyswitch:
- compact_routes="auto" uses a side-effect-free compiled CPython bytecode-size proxy instead of AST-node count.
- Context-dependent tails fail closed.
- Public telemetry: auto_compact_plans and auto_compact_estimated_bytes_saved.
- Default compact_routes=False remains unchanged.

pygoto:
- Every emitted goto and label-skip native jump is proven against the final CFG: exact opcode/target, CFG terminator placement, jump successor, and strict source exception signature.
- One verified CFG is reused for the feature proof and report.
- Public telemetry includes cfg_verification_passes=1.

Safety notes
------------
- No new self-modifying behavior is added to the production portable switch path.
- Guarded closure fallback reuses the exact object loaded from the closure cell; rebinding does not cause a second closure read.
- Identity-only guarded inlining is deliberately not applied to mutable-keyword partials or generic callable instances.
- Switch auto-compaction never executes user code during its size estimate and fails closed for unsupported lexical contexts.
- pygoto strict mode still rejects protected-region violations and additionally proves each final synthetic CFG edge.
