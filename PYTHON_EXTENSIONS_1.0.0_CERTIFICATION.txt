python_extensions 1.0.0 production certification
==============================================

Runtime
-------
CPython 3.13.5
Production defaults remain portable/strict. Explicit switch live modes and goto unsafe mode remain opt-in.

Release hardening
-----------------
- Package status promoted to Production/Stable.
- Source-tree pytest configuration now declares the src/ layout; no PYTHONPATH workaround is required.
- Inline registry, weak identity set, and synthetic-name allocation are serialized with a re-entrant lock during decoration/registration. Transformed runtime hot paths acquire no new locks.
- python_extensions.switch, python_extensions.inline, and python_extensions.goto expose a coherent 1.0.0 module version.
- 0.22.0 safe defaults and transformation semantics are retained.

Production safety position
--------------------------
- pyswitch mode=auto/portable is the production default and does not self-modify executable bytecode.
- inline transformations happen at decoration time and preserve explicit conservative fallbacks for unsupported or unprofitable shapes.
- pygoto mode=strict validates protected-region behavior and proves final synthetic CFG edges.
- Experimental live/self-modifying switch backends and goto mode=unsafe are deliberately not production defaults.
