python_extensions 1.0.1 production hardening certification
=========================================================

Release target
--------------
- Distribution: cpython-extensions 1.0.1
- Import package: python_extensions
- Runtime target: CPython >=3.13,<3.14
- Certification interpreter: CPython 3.13.5
- Production defaults remain semantics-safe: portable switch, guarded inline,
  strict goto. Explicit live/self-modifying switch modes and unsafe goto remain
  opt-in compatibility/research paths.

Deep-audit corrections in 1.0.1
-------------------------------
- Inline registration lifecycle is transactional across temporary registration,
  successful replacement, rollback, unregistration, and weak-reference cleanup.
- Failed inline decoration no longer leaves a hidden registered identity.
- Same-named methods and independently-created local/factory functions no longer
  compete for a registry slot keyed only by a short function name.
- Registry/current/original identities are ref-counted weakly and cleaned without
  introducing locking on transformed runtime hot paths.
- The dormant native-match switch compiler, unreachable from the production
  lowering path, was removed.
- Release version metadata has one source of truth and the distribution carries
  a PEP 561 py.typed marker.
- The sdist retains historical benchmark/certification evidence referenced by the
  long-form README while excluding generated caches.
- The redundant PEP 517 wheel build requirement was removed; setuptools>=75
  supplies the wheel build command used by this release.
- The distribution name is cpython-extensions; the python_extensions import API is
  unchanged. This avoids collision with an unrelated normalized distribution name.
- Switch marker parsing accepts exact aliases and qualified public forms such as
  pe.switch / pe.case / pe.fallthrough without invoking arbitrary attribute hooks.
- Reproducible release tooling builds the wheel under a fixed SOURCE_DATE_EPOCH
  and canonically repacks the setuptools-selected sdist with fixed ordering,
  ownership, and timestamps.

Scope boundary
--------------
This certification is for the CPython 3.13.5 build used above. Concurrency and
registry locking were exercised with threads, but a free-threaded CPython 3.13t
interpreter was not available in this environment and is therefore not claimed
as independently certified by this file.
